📦 client-custom-logs

یک ماد سبک وزن برای فابریک که لاگ‌های اختصاصی را بدون تأثیر بر لاگ اصلی ماینکرفت نمایش می‌دهد.

🇮🇷 فارسی (راست‌چین)
Fabric Minecraft Log4j2 Java

✨ ویژگی‌های کلیدی

  • 📝 قالب لاگ‌های سفارشی برای ماد شما
  • 🖥️ نمایش جداگانه در کنسول ماینکرفت
  • 🔒 قالب اصلی لاگ ماینکرفت بدون تغییر می‌ماند
  • 📁 بدون ایجاد فایل لاگ جدید برای latest.log
  • ⚙️ تنظیمات Log4j2 از منابع ماد بارگذاری می‌شود
  • 🧩 API ساده برای نوشتن لاگ‌های سفارشی

⚙️ نحوه کار

ماد یک لاگر اختصاصی Log4j2 با نام yourid ایجاد می‌کند.

public static final String MOD_ID = "yourid";
public static final Logger LOGGER = LogManager.getLogger(MOD_ID);

سپس می‌توانید پیام‌ها را به این صورت بنویسید:

LOGGER.info("Loading Mod...");
LOGGER.warn("This is a warning.");
LOGGER.error("Something went wrong.");

پیام‌های سفارشی با فرمت زیر نمایش داده می‌شوند:

[15:20:10] [Custom Format/INFO]: Loading Mod...
[15:20:11] [Custom Format/WARN]: This is a warning.
[15:20:12] [Custom Format/ERROR]: Something went wrong.

در همین حال، لاگ‌های معمولی ماینکرفت به فرمت پیش‌فرض خود ادامه می‌دهند:

[15:20:10] [Render thread/INFO]: Minecraft message

📂 تنظیمات Log4j2

ماد فایل تنظیمات خود را از مسیر زیر بارگذاری می‌کند:

src/main/resources/logs/log4j2.xml

لاگر سفارشی به این شکل تعریف می‌شود:

<Logger name="yourid" level="info" additivity="false">
    <AppenderRef ref="youridConsole"/>
</Logger>

گزینه additivity="false" از چاپ دوباره پیام‌ها جلوگیری می‌کند.

فرمت کنسول سفارشی:

<Console name="youridConsole" target="SYSTEM_OUT">
    <PatternLayout pattern="[%d{HH:mm:ss}] [Custom Format/%level]: %msg{nolookups}%n" />
</Console>

📄 فایل لاگ ماینکرفت

فایل لاگ اصلی ماینکرفت همچنان مسئول logs/latest.log است. ماد ما فایل جدیدی ایجاد نمی‌کند و از تداخل با فایل لاگ اصلی جلوگیری می‌کند.

🧑‍💻 نحوه استفاده

یک لاگر در کلاس اصلی ماد خود ایجاد کنید:

package com.mymod;

import net.fabricmc.api.ClientModInitializer;
import net.minecraft.util.Identifier;
import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;
import org.apache.logging.log4j.core.LoggerContext;

public class MyMod implements ClientModInitializer {
    public static final String MOD_ID = "mymod";
    public static final Logger LOGGER = LogManager.getLogger(MOD_ID);

    public static Identifier id(String path) {
        return new Identifier(MOD_ID, path);
    }

    @Override
    public void onInitializeClient() {
        try {
            var configUrl = getClass().getResource("/logs/log4j2.xml");

            if (configUrl != null) {
                LoggerContext context = (LoggerContext) LogManager.getContext(false);
                context.setConfigLocation(configUrl.toURI());
                context.reconfigure();      
                LOGGER.info("Loading Mod...");
            } else {
                LOGGER.error("[Custom Format] Could not find log4j2.xml");
            }
        } catch (Exception e) {
            LOGGER.error("[Custom Format] Failed to load log4j2.xml: " + e.getMessage());
            e.printStackTrace();
        }
        LOGGER.info("Hello from my mod!");
    }
}

خروجی نهایی:

[15:20:09] [Custom Format/INFO]: Loading Mod...
[15:20:10] [Custom Format/INFO]: Hello from my mod!

❓ چرا از این ماد استفاده کنیم؟

لاگر پیش‌فرض ماینکرفت برای پیام‌های عمومی مفید است، اما مادهای بزرگ می‌توانند خروجی زیادی تولید کنند. این ماد قالبی اختصاصی برای پیام‌های شما فراهم می‌کند تا تشخیص آنها آسان‌تر باشد:

[Custom Format/INFO]
[Custom Format/WARN]
[Custom Format/ERROR]

این ویژگی مخصوصاً هنگام توسعه یا دیباگ مادهای فابریک بسیار مفید است.
